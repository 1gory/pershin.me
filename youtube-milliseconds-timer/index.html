YouTube Milliseconds Timer

YouTube shows time in whole seconds. This extension shows the milliseconds, right in the player, and adds tools to jump to, measure and copy an exact moment.

A second is a long time

When you sync a subtitle line, time a speedrun split or cite the moment a ball crossed the line, a whole second is too coarse. YouTube rounds everything to seconds, so you end up scrubbing back and forth and guessing.

YouTube Milliseconds Timer replaces the player clock with 1:23.456 and puts a few precise tools next to it. Nothing covers the video: the buttons sit in the control bar, and the ones you never use can be hidden.

What people use it for

Subtitles and captions

Find where a line starts and ends to the millisecond and copy the time straight into your subtitle file or editor, instead of nudging timings by ear.

Editing and research

Log cue points from a reference video, note exactly when something happens in a recording, or build a shot list with precise times.

Sport and speedruns

Mark the start and the finish with the A→B timer and read the difference: a sprint, a reaction time, a split.

Teaching and sharing

Send students or colleagues to the exact moment: jump there with G and copy the time in one click.

Features

Millisecond timestamps

The player clock reads 1:23.456 instead of 1:23. It replaces YouTube’s own time display, so there is no overlay on the video. One button turns milliseconds off when you don’t need them.

Jump to an exact time

Press G or the target button, type SS.mmm, M:SS.mmm or H:MM:SS.mmm and press Enter. The field opens with the current time filled in, so you only change the digits you need.

A→B interval timer

Press [ at the start and ] at the end. A badge above the controls shows the difference to the millisecond, the range is marked on the progress bar, and one click copies it.

One-click copy

A copy button next to the clock puts the current time on your clipboard. The extension touches the clipboard only when you click it.

Watch-time statistics

Today, total, a daily average over 7 days, 30 days or all time, a 7-day chart and a monthly calendar you can page back through. Stored only on your device.

Only the buttons you use

Hide any player button: copy, the milliseconds toggle, jump or the A/B pair. The shortcuts work on Cyrillic and other non-Latin keyboard layouts too.

How it works

  1. Install it from the Chrome Web StoreIt runs only on youtube.com.
  2. Open any videoThe clock in the player now shows milliseconds, and the new buttons appear next to it.
  3. Jump, measure, copyG to jump, [ and ] to measure, the copy button to grab the time. Settings and your watch-time stats live in the toolbar popup.

Questions

Does it collect any data?

No. There is no account, no analytics and no network requests. Settings and watch-time statistics are stored in Chrome’s local storage on your device. Details are in the privacy policy.

Why does it need access to youtube.com?

To replace the player’s time display and add its buttons to the control bar. It does not run on any other site.

Is it free?

Yes, free and open source under the MIT license. The code is on GitHub.

Can I install it without the Chrome Web Store?

Yes. Download the ZIP from GitHub Releases, unzip it, open chrome://extensions, turn on Developer mode and choose “Load unpacked”.

Where do I report a bug or suggest an idea?

Leave a review in the Chrome Web Store (the popup has a link) or open an issue on GitHub.
